GitHub topic — data contracts

github-search source · weekly cadence · 0 drafts contributed

What this source is

GitHub topic — data contracts enters the discovery pipeline as a GitHub repository search — new matching repos are classified as they appear. Content lands in the ingestion pipeline, where it is classified against the taxonomy and written to a human-reviewed draft queue — nothing auto-publishes.

Cadence, authority and routing

Fetched weekly. Authority weight 3/5 feeds the source-quality score, so content from vetted publishers ranks higher before any human review. Discovered items default to the cat-governance category.

Contribution to the registry

No drafts recorded yet. New sources enter the rotation and produce drafts on their first successful fetches — absence here means not yet crawled into a draft, not absence of content.

Verify against the source

Every registry claim should be checkable at its origin: https://api.github.com/search/repositories?q=topic:data-contracts+sort:updated&per_page=15. If this source ever becomes unreachable, it is skipped with a warning — the pipeline records the failure and the rest of the run continues.

How discovery works

FETCH → EXTRACT → CLASSIFY → DRAFT. A weekly GitHub Action runs the discovery loop, opens one PR per batch, and a human curator accepts, edits or rejects each item. Scores are computed, never hand-written — see the scoring model and verification levels.
