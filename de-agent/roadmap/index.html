The Data Engineering Roadmap

13 stages from Foundations to Agentic Data Engineering. Each has an exit gate you can prove and a deliverable artifact.

Phase 1 — Foundations

Storage, compute, and the primitives everything else builds on.

  1. 01 Foundations How data systems actually work — storage, compute, encoding, and the vocabulary you'll use for the next decade. 10 guides & tools · 6 further reading
    Gate You can describe a data system's lifecycle and where cost and latency come from. · Deliverable: Fundamentals of Data Engineering (O'Reilly)

    You can, after this stage

    • explain the data lifecycle
    • read an architecture diagram
    • reason about storage vs compute

    Core

    Engineering Foundations

    Filesystems, encoding, memory vs disk, networks and the operating vocabulary behind every pipeline.

    4 resources

    Storage

    Data Structures & Formats

    Row vs columnar, Parquet vs ORC vs Avro, encoding, compression and predicate pushdown.

    12 resources
  2. 02 Python + SQL The two languages everything else is built from. Fluency here is the single highest-leverage investment. 15 guides & tools · 4 further reading
    Gate You can move a dataset from an API into a table with tested code. · Deliverable: dbt → warehouse → tests → docs

    You can, after this stage

    • write set-based SQL
    • write testable Python
    • move data between the two

    Language

    Python

    Typing, packaging, virtualenvs and the data libraries (pandas, polars, pyarrow) you'll actually reach for.

    1 resource

    Language

    SQL

    Set-based thinking, window functions, CTEs and query plans. The highest-ROI skill in the field.

    18 resources
  3. 03 Data Processing Batch engines, file formats, and the mechanics of turning raw bytes into queryable tables. 22 guides & tools · 4 further reading
    Gate You can build and re-run a batch pipeline safely. · Deliverable: API → S3 → Spark → Parquet

    You can, after this stage

    • build a batch pipeline
    • choose a file format
    • control partitioning

    Storage

    Databases

    OLTP systems, indexes, transactions, replication and how operational data is born.

    4 resources

    Processing

    Spark / PySpark

    Distributed dataframes: lazy DAGs, shuffles, skew, partitioning and physical plans.

    14 resources

    Processing

    Batch Processing

    Incremental vs full reload, watermarks, idempotent writes and reprocessing strategy.

    6 resources

    Processing

    APIs & Ingestion

    Pulling from REST/GraphQL APIs: pagination, rate limits, idempotency keys and incremental syncs.

    1 resource

    Processing

    File & Partner Ingestion

    Landing CSV/XML/EDI drops safely: manifesting, validation, late and duplicate files.

    1 resource
