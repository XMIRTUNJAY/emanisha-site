    Marathi Sentence Scramble

    Sentence Scramble

    Real sentences from the Bol Marathi curriculum, shuffled. Put the tiles back in order — Marathi runssubject → object → verb, so the verb lands last.

    How to play
    1. Read the English prompt, then tap tiles to move them between the bank and your sentence.
    2. Reorder inside your sentence by dragging a tile or focusing it and using ←/→.
    3. Check compares against the curriculum order (plus any accepted alternatives).
    4. Stuck? Hint shows the grammar pattern, then places the first tile.
