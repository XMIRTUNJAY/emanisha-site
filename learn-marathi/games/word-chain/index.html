    Marathi Word Chain · शब्दसाखळी

    Word Chain

    Chain Marathi words end-to-end: each new word must begin with the last letter of the previous one — घर → रंग. Words come from the curriculum vocabulary, so the chain is always real.

    How to play
    1. Each turn shows four words — pick the one that follows the chain rule.
    2. Rule: the next word's first letter must match the previous word's last letter (vowel signs don't count): घर → रंग, बाई → ईश.
    3. Prefer typing? Switch to Type mode and write any word from the dictionary in Devanagari.
    4. A run lasts 10 turns. Stuck? Ask for a hint.
