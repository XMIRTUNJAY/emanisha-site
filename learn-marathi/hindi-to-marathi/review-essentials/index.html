    What you will learn

    A review bridge pulling the highest-leverage patterns from Units 01–20: fused forms (पाहिजे, नको, मला), sound shifts (मदद→मदत, तयार, चावी), three genders (माझा/माझी/माझे), continuous tense (तो+आहे), question words (काय, कुठे, कधी, कसे, कोण, का), and the dative pattern for feelings/symptoms (मला…आहे). Each row is a Hindi→Marathi mapping with the one note that makes it stick.

    This page is the pre-trip or pre-exam checklist — if these 20 rows are automatic, the rest of the course builds on solid ground.

    Tip: If you know these 20 rows cold, you have the skeleton of Marathi. Everything else is vocabulary hanging on this frame.

    The 5 fused forms to never forget

    1) चाहिए → पाहिजे 2) नहीं चाहिए → नको 3) मुझे → मला 4) को/से/के लिए → कडून/साठी 5) यह/वह → हा/ही/हे, तो/ती/ते. These appear in every conversation.

    The 3 sound shifts that cover 80%

    1) Hindi द/द → Marathi त/त (मदद→मदत, चाबी→चावी, सब्जी→भाजी spirit). 2) Hindi nasal drop (महँगा→महाग, गंगा→गंगा same). 3) Hindi आ → Marathi अ/अ (तयार, आरसा).

    Common mistakes

    ✗ Using all Hindi postpositions separately→✓ Marathi fuses them: मुझे→मला, को→कडून

    Fused forms are mandatory, not optional — they are the grammar.

    ✗ Dropping the neuter gender→✓ Neuter is real: ते, हे, माझे, सोपे, खाते आहे

    Hindi has two genders; Marathi has three. Ignoring neuter breaks agreement everywhere.

    ✗ Keeping रहा/रही in continuous→✓ तो+आहे, ती+आहे, ते+आहे — never रहा

    The marker is the verb root + तो/ती/ते + आहे. रहा has no place in Marathi.

    Quick practice

    Answer first, then open the reveal to check yourself.

    1. “I need” in Marathi?
    1. मी हवा
    2. मला पाहिजे
    3. मी मागतो
    4. माझं आहे

    Answer: B. मला पाहिजे — मला पाहिजे — the fused need form.

    2. Continuous “he is going”?
    1. तो जा रहा आहे
    2. तो जात आहे
    3. तो गेला आहे
    4. तो जाईल आहे

    Answer: B. तो जात आहे — तो जात आहे — root जा + तो + आहे.

    3. Neuter “this book”?
    1. हा पुस्तक
    2. ही पुस्तक
    3. हे पुस्तक
    4. हो पुस्तक

    Answer: C. हे पुस्तक — पुस्तक is neuter → हे पुस्तक.

    4. Translate to Marathi: “मुझे पानी चाहिए।”

    मला पाणी पाहिजे. — Fused need + dative — the pattern from Unit 01.

    Common questions

    What are the top 5 Hindi→Marathi patterns to master first?

    1) पाहिजे/नको (need/don't want) 2) मला (to me) 3) कडून/साठी (from/for) 4) तो+आहे (continuous) 5) हा/ही/हे (gendered this).

    Do I need to learn all three genders?

    Yes — neuter is not optional. Words like पाणी (water), पुस्तक (book), घर (house), खाते (eating) are neuter and appear constantly.
