    Patterns to notice

    • नमस्ते → नमस्कार — नमस्कार is used anytime.
    • मेरा नाम → माझं नाव — नाव = name.
    • तुम कैसे हो → तू कसा आहेस — कसा masc, कशी fem.
    • मैं खा रहा हूँ → मी खातो आहे — Continuous = verb+तो + आहे.
    • मुझे चाहिए → मला पाहिजे — मला पाहिजे = I need.
    • वह चावल खाता है → तो भात खातो — भात = rice.
    • तैयार → तयार — तयार = ready.
    • मदद → मदत — मदत = help.
    • मेरा → माझं — Possessive agreement.
    • क्या कहाँ कब कैसे कौन → काय कुठे कधी कसे कोण — Question words stay in place.
    • आइए जाइए खाइए → या जा खा — Imperative forms.
    • चाहिए नहीं चाहिए → पाहिजे नको — पाहिजे = need. नको = don't want.
