    What you will learn

    Twelve Marathi bird names from the Bol Marathi curriculum — from the everyday चिमणी (sparrow) and कोबळ (pigeon) to the majestic मोर (peacock) and गरुड (eagle). Each entry has Hindi and English meanings, pronunciation and a real example sentence.

    Several Hindi bird names shift systematically in Marathi: कबूतर → कोबळ, तोता → पोपट, उल्लू → उड्डाण, कौवा → काक. The table below maps each shift so you learn the pattern once.

    Tip: कोबळ, पोपट, काक, शकुन — these four shifts cover the most common birds. Learn the pattern once: retroflex + vowel shift.

    Everyday birds you will see

    चिमणी (sparrow), कोबळ (pigeon), काक (crow) — these three are everywhere in Maharashtra. चिमणी छोटी आहे (the sparrow is small), कोबळ खिडकीवर बसले (pigeon sat on the window), काक कावतो (crow caws) — the curriculum sentences put them in daily life.

    Cultural & iconic birds

    मोर (peacock) — India's national bird, नाचतो आहे in monsoon. कोयल (koel) — the spring singer, बसंतऋतूचे प्रतीक. गरुड (eagle) — mythological vehicle of Vishnu. शकुन (kite/hawk) — high flier. Each carries cultural weight beyond vocabulary.

    The systematic shifts

    कबूतर → कोबळ, तोता → पोपट, उल्लू → उड्डाण, कौवा → काक, बगुला → बगळा. The pattern: Hindi retroflex + vowel shifts to Marathi ळ or ण or shortened form. Learn these five; the rest are identical (मोर, हंस, कोयल, गरुड, पक्षी).

    Common mistakes

    ✗ Saying कबूतर for pigeon→✓ कोबळ — the Marathi word

    Systematic shift: Hindi कबूतर → Marathi कोबळ. The retroflex + vowel change is regular.

    ✗ Using तोता for parrot→✓ पोपट — the Marathi word

    तोता → पोपट follows the same retroflex shift pattern.

    ✗ Calling any bird पक्षी→✓ पक्षी = bird (generic); use species names

    पक्षी is the category word. For specific birds, use कोबळ, पोपट, मोर, etc.

    Quick practice

    Answer first, then open the reveal to check yourself.

    1. How do you say "peacock" in Marathi?
    1. मोर
    2. कोयल
    3. पोपट
    4. गरुड

    Answer: A. मोर — मोर (mor) — national bird, identical to Hindi.

    2. What is पोपट?
    1. Pigeon
    2. Sparrow
    3. Parrot
    4. Crow

    Answer: C. Parrot — पोपट (popaṭ) = parrot; Hindi तोता shifts to पोपट.

    3. Which bird is कोयल?
    1. Peacock
    2. Koel/cuckoo
    3. Eagle
    4. Sparrow

    Answer: B. Koel/cuckoo — कोयल (koyal) = koel/cuckoo, the spring singer.

    4. Translate to Marathi: “The peacock is dancing.”

    मोर नाचतो आहे. — Monsoon behaviour — Unit 14 sentence.
