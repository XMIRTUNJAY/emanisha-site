    What you will learn

    Sixty-eight Marathi adjectives covering size (मोठा/लहान), quality (चांगला/वाईट), temperature (गरम/थंड), difficulty (सोपं/अवघड) and opposite pairs (उघडा/बंद, कोरडा/ओला, जड/हलका). Every entry has Hindi and English meanings, pronunciation and a real example sentence.

    Unit 3 teaches adjective agreement: मोठा (masculine), मोठी (feminine), मोठे (neuter). The table below gives the masculine citation form; the possessives page (माझा/माझी/माझे) shows the same pattern — learn them together.

    Tip: Learn opposite pairs together: मोठा/लहान, चांगला/वाईट, गरम/थंड, उघडा/बंद — pairs stick faster than singles.

    Gender agreement — the one rule to watch

    Adjectives ending in -ा (मोठा) change to -ी (मोठी) for feminine nouns and -े (मोठे) for neuter. The noun decides — माझा मोठा घर (my big house, neuter) but माझी मोठी बहीण (my big sister, feminine). The possessives page drills this exact pattern.

    Opposite pairs you will use daily

    उघडा/बंद (open/closed), कोरडा/ओला (dry/wet), जड/हलका (heavy/light), मऊ/कडक (soft/hard), रुंद/अरुंद (wide/narrow), खोल/उंच (deep/tall). Each pair is a ready-made mini-lesson.

    Common mistakes

    ✗ Using मोठा with a feminine noun→✓ मोठी बहीण (big sister) — adjective matches noun gender

    The citation form मोठा is masculine; feminine nouns take मोठी, neuter take मोठे.

    ✗ Confusing थंड (adj) and थंडी (noun)→✓ थंड = cold (adjective); थंडी = cold weather / winter (noun, feminine)

    Weather page uses थंडी as noun; here थंड is the describing word.

    ✗ Writing चांगला for a neuter noun→✓ चांगले पाणी (good water) — neuter takes -े

    Same agreement rule as possessives: माझे, चांगले, सोपे.

    Quick practice

    Answer first, then open the reveal to check yourself.

    1. How do you say “small” in Marathi?
    1. मोठा
    2. लहान
    3. चांगला
    4. वाईट

    Answer: B. लहान — लहान (lahān) — opposite of मोठा.

    2. Fast in Marathi is…
    1. हळू
    2. जलद
    3. सोपं
    4. अवघड

    Answer: B. जलद — जलद (jalad) = fast; opposite is हळू (slow).

    3. Which pair means “easy / difficult”?
    1. गरम/थंड
    2. सोपं/अवघड
    3. उघडा/बंद
    4. जड/हलका

    Answer: B. सोपं/अवघड — सोपं = easy, अवघड = difficult.

    Do Marathi adjectives change for gender?
