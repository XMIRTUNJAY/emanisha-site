    What you will learn

    Twenty-five Marathi household words — the room (घर, खोली), the fixtures (दार, खिडकी, दिवा, आरसा), the furniture (टेबल, खुर्ची, पलंग), and the everyday carry (चावी, पैसा, मोबाईल, बूट). Every entry has Hindi and English meanings, pronunciation and a real example sentence.

    The daily-life cluster page mixes 5 categories; this page isolates the home subset so you can learn the room-by-room vocabulary without distraction. Units 2 and 3 sentences like पुस्तक बॅगमध्ये आहे and माझी खोली स्वच्छ आहे put these words in context.

    Tip: खोली = room (specific); घर = house/building (whole). Hindi कमरा/घर follows the same split — the distinction carries over.

    Room vs house

    माझी खोली स्वच्छ आहे (my room is clean) vs माझे घर मोठे आहे (my house is big). The agreement follows the noun — खोली (feminine) takes माझी/स्वच्छ, घर (neuter) takes माझे/मोठे.

    Mirrors and keys — Hindi speakers take note

    आरसा (mirror) vs Hindi आईना — completely different word. चावी (key) vs Hindi चाबी — same root, Marathi spelling. Both are high-frequency in daily instructions: आरसा बघा (look in the mirror), चावी द्या (give the key).

    Common mistakes

    ✗ Using घर for “room”→✓ घर = house; खोली = room

    Same distinction as Hindi घर/कमरा — mixing them makes you sound like you live in one room.

    ✗ Saying आईना for mirror→✓ आरसा = mirror (Marathi); आईना is Hindi

    One of the clearest Hindi→Marathi swaps on this page — no sound overlap, must learn fresh.

    ✗ Writing चाबी for key→✓ चावी = key (Marathi spelling)

    The व/ब shift is systematic: Hindi ब → Marathi व in many loans (चाबी→चावी, सब्जी→भाजी in spirit).

    Quick practice

    Answer first, then open the reveal to check yourself.

    1. Mirror in Marathi is…
    1. आईना
    2. आरसा
    3. दार
    4. खिडकी

    Answer: B. आरसा — आरसा (ārsā) — distinct from Hindi आईना.

    2. What is चावी?
    1. Money
    2. Key
    3. Address
    4. Shoes

    Answer: B. Key — चावी (cāvī) = key; पैसा = money, पत्ता = address, बूट = shoes.

    3. बूट means…
    1. Socks
    2. Shoes/boots
    3. Belt
    4. Bag

    Answer: B. Shoes/boots — बूट (būṭ) — shoes/boots; चप्पल = sandals/slippers.

    4. Translate to Marathi: “The book is in the bag.”
