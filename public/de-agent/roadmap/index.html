Learning roadmap

The Data Engineering Roadmap

13 stages from Foundations to Agentic Data Engineering. Each has an exit gate you can prove and a deliverable artifact.

  1. 01 Foundations How data systems actually work — storage, compute, encoding, and the vocabulary you'll use for the next decade. 2 resources

    Core

    Engineering Foundations

    Filesystems, encoding, memory vs disk, networks and the operating vocabulary behind every pipeline.

    1 resources

    Storage

    Data Structures & Formats

    Row vs columnar, Parquet vs ORC vs Avro, encoding, compression and predicate pushdown.

    1 resources
  2. 02 Python + SQL The two languages everything else is built from. Fluency here is the single highest-leverage investment. 7 resources

    Language

    Python

    Typing, packaging, virtualenvs and the data libraries (pandas, polars, pyarrow) you'll actually reach for.

    0 resources

    Language

    SQL

    Set-based thinking, window functions, CTEs and query plans. The highest-ROI skill in the field.

    7 resources
  3. 03 Data Processing Batch engines, file formats, and the mechanics of turning raw bytes into queryable tables. 15 resources

    Storage

    Databases

    OLTP systems, indexes, transactions, replication and how operational data is born.

    3 resources

    Processing

    Spark / PySpark

    Distributed dataframes: lazy DAGs, shuffles, skew, partitioning and physical plans.

    7 resources

    Processing

    Batch Processing

    Incremental vs full reload, watermarks, idempotent writes and reprocessing strategy.

    3 resources

    Processing

    APIs & Ingestion

    Pulling from REST/GraphQL APIs: pagination, rate limits, idempotency keys and incremental syncs.

    1 resources

    Processing

    File & Partner Ingestion

    Landing CSV/XML/EDI drops safely: manifesting, validation, late and duplicate files.

    1 resources
  4. 04 Warehousing Modelling, transformation and serving — dimensional design, dbt, and warehouse-native patterns. 15 resources

    Serving

    Data Warehouses

    Columnar MPP serving layers, dimensional modelling, marts and semantic layers.

    5 resources

    Serving

    dbt

    Analytics engineering as software: models, refs, tests, docs and incremental materialisations.

    10 resources
  5. 05 Lakehouse Open table formats that give object storage ACID, time travel and schema evolution. 10 resources

    Storage

    Data Lakes

    Object-storage data lakes, zones (raw/curated), partitioning strategy and the small-files problem.

    2 resources

    Storage

    Lakehouse

    Delta Lake, Apache Iceberg and Hudi — ACID tables on object storage with time travel and evolution.

    8 resources
  6. 06 Orchestration Scheduling, dependencies, retries, backfills and idempotency across many moving parts. 9 resources

    Orchestration

    Airflow / Orchestration

    DAGs, operators, task state, retries, backfills and the difference between scheduling and dependency management.

    9 resources
  7. 07 Streaming Event-driven ingestion, log-based CDC, windowing, and exactly-once semantics under load. 17 resources

    Processing

    Streaming

    Event time vs processing time, windowing, watermarks, delivery guarantees and state.

    5 resources

    Processing

    Kafka

    Topics, partitions, consumer groups, offsets, retention and lag diagnosis.

    7 resources

    Processing

    CDC

    Change data capture: log-based vs query-based, ordering, deletes and merge strategies.

    5 resources
  8. 08 Cloud Provider primitives — object storage, managed compute, IAM, and the platform-specific data stack. 19 resources

    Cloud

    AWS

    S3, Glue, Athena, Kinesis, Redshift, EMR and IAM — the most common data platform in the world.

    9 resources

    Cloud

    Azure

    ADLS, Synapse, Data Factory, Fabric and Entra ID for the Microsoft-shaped data stack.

    0 resources

    Cloud

    GCP

    BigQuery, Cloud Storage, Dataflow, Pub/Sub and Dataproc.

    2 resources

    Cloud

    Databricks

    Delta Lake, Unity Catalog, jobs, DLT pipelines and the lakehouse platform.

    2 resources

    Cloud

    Snowflake

    Virtual warehouses, micro-partitions, clustering, streams/tasks and Snowpark.

    3 resources

    Platform

    Infrastructure / Docker / Terraform

    Containers, images, IaC and reproducible environments for pipelines and platforms.

    1 resources

    Platform

    CI/CD

    Testing, packaging and deploying data code — including data-aware CI and safe promotion.

    2 resources
  9. 09 Data Quality Contracts, expectations, quarantine and the tests that keep a table trustworthy on Monday morning. 17 resources

    Quality

    Data Quality

    Expectations, completeness, uniqueness and quarantine flows that stop bad data reaching consumers.

    8 resources

    Quality

    Data Contracts

    Versioned producer/consumer agreements: schema, semantics, SLAs and breaking-change policy.

    9 resources
  10. 10 Observability Knowing what a pipeline did without reading its code — metrics, freshness, lineage and cataloguing. 7 resources

    Quality

    Data Observability

    Freshness, volume, schema and distribution monitoring with automated anomaly detection.

    1 resources

    Quality

    Data Lineage

    Column-level provenance — what broke, what depends on it and where to fix it.

    3 resources

    Quality

    Data Catalog

    Discoverability: technical and business metadata, ownership, glossary and search.

    3 resources
  11. 11 Reliability Operating data systems for years — SLOs, incident response, cost control and safe change. 21 resources

    Operations

    Security

    Least privilege, secrets, PII handling, masking and secure data sharing.

    3 resources

    Operations

    Governance

    Access policy, retention, residency, audit and stewardship at organisational scale.

    4 resources

    Operations

    Cost Engineering

    Unit economics of data — attribution, reducing shuffle/scan, and stopping 4x regressions.

    7 resources

    Operations

    Reliability

    SLOs, error budgets, retries vs idempotency, graceful degradation and incident review.

    2 resources

    Quality

    Testing

    Unit, integration and data tests; fixtures, contracts and CI gates for pipelines.

    1 resources

    Operations

    Production Operations

    Day-two work: monitoring, on-call, backfills, deployments and capacity.

    4 resources
  12. 12 System Design Choosing architectures under real constraints and defending the tradeoffs in an interview. 1 resources

    Practice

    Data Engineering System Design

    Sizing, throughput, tradeoffs and communicating an architecture under interview pressure.

    1 resources
  13. 13 Agentic Data Engineering Using coding agents as first-class data engineers — skills, MCP servers, hooks and guardrails. 16 resources

    Practice

    Agentic Data Engineering

    Skills, MCP servers, agents and hooks that let coding agents do real data engineering safely.

    16 resources

    Practice

    AI / ML Data Infrastructure

    Feature stores, embeddings, vector indexes, training data pipelines and retrieval infra.

    0 resources
